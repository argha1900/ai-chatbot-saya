```bash
# Clone atau download folder Html_GhaaHub2025Web
```

### 2. Setup Local Server
```bash

```


## 🎨 Customization

### Mengubah Warna Theme
```css
/* Di file css/style.css */
:root {
    --primary-color: #00d4ff;
    --secondary-color: #0099cc;
    --accent-color: #ff6b6b;
}
```

### Mengubah Animasi
```javascript
// Di file js/animations.js
const animationController = new AnimationController();
```

### Mengubah Particle System
```javascript
// Di file js/particles.js
const particleSystem = new ParticleSystem(container, {
    particleCount: 50,
    particleColor: 'rgba(0, 212, 255, 0.6)',
    particleShape: 'circle'
});
```
